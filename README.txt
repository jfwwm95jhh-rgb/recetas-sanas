# RECETAS SANAS — prototipo PWA

Prototipo funcional de la app definida en la conversación.

Incluye:
- Inicio, búsqueda y filtros
- Crear receta manualmente
- Foto: cámara, fotos o añadir después
- 4 pasos de creación
- Ingredientes con cantidades obligatorias
- Comensales 2–12 en saltos de 2
- Recalculo de ingredientes al cambiar comensales
- Borradores con porcentaje
- Favoritos (estructura inicial)
- Lista de compra
- Compartir receta mediante el menú del dispositivo
- Configuración
- PWA instalable

Nota: esta primera versión guarda datos localmente en el navegador. La biblioteca compartida Alex + Marta y la sincronización iCloud real requieren conectar un backend/servicio de autenticación y base de datos en la siguiente fase.
